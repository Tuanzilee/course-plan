# course-plan｜輔大心理系畢業學分儀表板

單頁 HTML + JSON 的自用畢業學分規劃工具。手機、電腦都能開。

## 是什麼

回答四個問題：

1. **還差多少？** 各分類（全人 32／院系 64／選修 32）的已修、在修、已排、缺口
2. **哪些還沒排？** 待修必修課依「只開上學期／只開下學期」分組
3. **這樣排會不會出事？** 擋修違規、開課學期錯配、學期學分上下限、衝堂、抵認上限
4. **抵免過了會怎樣、沒過會怎樣？** 右上角 Plan A / Plan B 一鍵切換，全部數字重算

## 怎麼跑

```bash
cd ~/Desktop/course && python3 -m http.server 4173
```

然後開 <http://localhost:4173>。

> 不能直接雙擊 `index.html`：頁面用 `fetch` 讀 JSON，`file://` 會被瀏覽器擋掉。
> 部署到 GitHub Pages 後就沒這問題。

## 檔案結構

```
index.html                 介面與計算邏輯（無框架、無外部相依）
data/requirements.json     畢業規定：分類門檻、學分上下限、抵認上限、待確認事項
data/courses.json          課程總表：學分、類別、建議年級、開課學期、擋修
data/my-record.json        我的紀錄：抵免申請、擋修放行、各學期修課
```

改資料只要編 `data/` 底下的 JSON，不用動 `index.html`。

## 排課盤怎麼用

在「排課盤」分頁把待修課丟進未來學期 → 總覽的學分與檢查即時重算。
編輯暫存在瀏覽器 localStorage，滿意後按 **匯出 my-record.json** 覆蓋 `data/my-record.json`，
再 commit 才會真的存下來。按 **還原成檔案內容** 可丟掉本機編輯。

## 目前已知的待確認事項

儀表板會把這些列在總覽的檢查區（來源：`requirements.json` 的 `openQuestions`）：

- **體育學分**：抵免申請書照 113 前舊制填 0 學分，但 114 新制大二體育每學期 1 學分要計入畢業學分
- **核心課程 57 取 45 的彈性**：除社會學／經濟學擇一外，其餘 12 學分能否略過要問系辦
- **抵認上限**：表 A+B+C 合計已超過轉入二年級的 50 學分上限，實際核可數額以教務處為準
- **必修表 vs 實際開課**：發展心理學（表列二上、實開下學期）、人格心理學（表列二下、實開上學期）
